# dropping in your own frames

1. draw at **1000 x 1800 px** and export a **PNG with transparency**. the frame
   can sit anywhere in that canvas; wherever you leave transparent is where the
   photos show through.
2. drop the file in this folder.
3. add an entry to `manifest.json`. it shows up in the booth on the next
   reload, no code change needed.

```json
{
  "id": "my-frame",
  "name": "my frame",
  "kind": "strip",
  "src": "/frames/my-frame.png",
  "background": "#fffcf0",
  "ink": "#7d1222",
  "art": { "left": 160, "width": 1000, "height": 1800 },
  "windows": [
    { "x": 240, "y": 260, "width": 520, "height": 240 },
    { "x": 240, "y": 530, "width": 520, "height": 320 },
    { "x": 240, "y": 860, "width": 520, "height": 320 },
    { "x": 300, "y": 1190, "width": 400, "height": 290 }
  ],
  "caption": 1620,
  "captionScale": 1
}
```

- `art` — where the drawing sits in your file. `left` is how far in from the
  left edge it starts; the strip crops to it, so the padding you exported with
  is thrown away. leave `art` out and the png is stretched to fill the strip.
- `windows` — your photo openings, measured **in your own file's pixels**. one
  per photo, top to bottom. there are four.
- `background` — shows anywhere the art is transparent and no photo covers it.
- `ink` — the caption colour. pick something readable on the caption band.
- `caption` — the height the caption is centred on, again in your file's
  pixels. use `null` if your art runs to the foot and leaves it nowhere to go,
  and the strip prints without one.
- `captionScale` — shrink the caption when the band is narrow. 1 is full size.

`pressed-border.svg` is generated by `scripts/make-stickers.mjs`, not drawn by
hand; delete it from the manifest once your own frames are in.
