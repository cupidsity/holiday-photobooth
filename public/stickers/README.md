# stickers

everything in this folder except your own files is generated by
`node scripts/make-stickers.mjs`. edit that script to change a shape, then run
it — it rewrites the svgs, `manifest.json` and `../frames/pressed-border.svg`.

## adding your own

1. export a **png with transparency**, roughly square, 256-512px a side. draw it
   as a flat pale silhouette or a fine pale line: the booth presses stickers
   into the print with a lighten blend, so anything darker than the paper will
   not show.
2. drop it here.
3. add it to `manifest.json`:

```json
{ "id": "my-sticker", "name": "my sticker", "group": "pressed", "src": "/stickers/my-sticker.png" }
```

`group` is the tray it lands in: `sigil`, `fine line` or `pressed`. an entry with
`"text": "merry"` instead of `src` becomes a word sticker in the caption font.
